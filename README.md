# Gaussian NBO Codex skill

A compact companion to the separately installed **Gauss-DFT-Ultimate** (`gaussian-dft-ultimate`) skill. Instructions are in Chinese; they cover embedded NBO discovery, checkpoint reuse, Windows Gaussian invocation, and donor–acceptor interpretation.

## Install

Copy the `gaussian-nbo` folder into your global Codex skills directory (`$CODEX_HOME/skills`, or `~/.codex/skills`), then reload skills or start a new session. Install `gaussian-dft-ultimate` separately.

Invoke `$gaussian-nbo` together with the main skill. Executable and job paths are discovered or supplied at runtime.

This repository contains instructions only. It includes no Gaussian/NBO binaries, licenses, calculation outputs, or machine configuration. Gaussian and external NBO require their own installations and licenses.
